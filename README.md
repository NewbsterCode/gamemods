# Newbster Code Game Mods

Save editors and tools for single-player games, one folder per mod.

| Game | Mod | Folder |
|---|---|---|
| SOVL: Fantasy Warfare | SOVL Campaign Editor | [`sovl/`](sovl/) |
| Dungeons & Dynasties | Dungeons & Dynasties save editor | [`dungeons-dynasties/`](dungeons-dynasties/) |

Each mod is self-contained: run and test it from its own folder (see its README).
Every mod backs up a save before changing it and never injects anything into a
running game.

Personal save files are never committed (see `.gitignore`).

Public pages: https://newbstercode.com/game-mods/
